# 【引き継ぎ用】投稿確認プレビューアプリ 仕様・デザインまとめ

このファイルは、**先方（クライアント）に渡す「アプリの使い方」資料をつくるための材料**です。
資料をつくるClaudeはこのアプリの実物を見られないので、ここに書いてある内容を正としてください。

読んでいる人（ぼんちゃん＝山中）はSNS運用代行者で、このアプリの制作者・運用者です。
資料を渡す相手は、アプリを**見る側**（社長・担当者）です。

---

## 0. まず結論：何のアプリか

SNSに投稿する前の動画とキャプションを、**実際のInstagram／YouTubeの画面そっくりの見た目**で
先方に見てもらい、その場で「これでOK」か「修正したい」を押してもらうためのWebアプリ。

- アプリのインストールは不要。**送られてきたURLをスマホのブラウザで開くだけ**
- ログインもパスワードもない
- 見る人がやることは実質**2つだけ**：動画を見る／ボタンを押す

これまでLINEやメールで「この動画どうですか」とやり取りしていたものを、
1つの画面にまとめて、誰がいつ何と言ったかが全部残るようにしたもの。

## 1. 登場人物と2つのURL

**コードは1つ、URLは2つ。**見せる相手も中身も違うので、データもURLも完全に分離している。

### A. 藤田鉄工所版

- 見る人：**米倉社長 / 吉田さん / 三浦さん**（3人）
- 画面に「プロジェクト」「プロダクト」「YouTube」の3つのタブがある
- 開くと最初に**「どなたとして確認しますか？」の名前選択画面**が出る

### B. KING PLANTS版

- 見る人：**小野寺さん**（1人）
- 「プロダクト」の投稿だけを共有するので、**タブは出ない**
- 確認者が1人なので、**名前選択画面も出ない**。開いたらいきなり投稿が表示される

> ⚠️ **2つのURLは互いに教えない。**片方の未公開案件がもう片方に見えてはいけないため。
> 資料も2種類つくるか、共通の1種類にするかは相談したい（→ §8）。

## 2. 画面の全体像

**1画面＝1投稿。上下スワイプで次の投稿に移る。**TikTokやリールを見るときと同じ動き。

```
┌─────────────────────┐
│ 藤田鉄工所      米倉社長 切り替える │ ← 上部バー（常に表示）
│ プロジェクト② プロダクト① YouTube① │ ← タブ（藤田鉄工所版のみ）
│                                     │
│                              ♡      │
│                              💬     │ ← 右のアイコン列（飾り・押せない）
│         （動画）             ➤      │
│                              🔖     │
│                              …      │
│                                     │
│ 🔴 fujita_stainless  フォロー       │ ← アカウント名（飾り）
│ ♪ 米津玄師・烏 - Raven              │ ← 音源名（飾り）
│ project 03／スクリュー… …続きを読む │ ← ここをタップすると全文
│                                     │
│ 確認待ち [これでOK] [修正したい]    │ ← ★実際に押すのはここだけ
│ ⌂  ▷  ➤  ⌕  ●                      │ ← アプリのタブバー（飾り）
└─────────────────────┘
```

### ここが分かりにくいポイント（資料で必ず触れたい）

**画面のほとんどは「飾り」です。**
いいね・コメント・シェア・保存・フォロー・下のタブバーは、
「投稿されたらこう見える」を再現しているだけで、押しても何も起きません。

**実際に触るのは3か所だけ：**

1. 動画（タップで再生）
2. キャプション（タップで全文）
3. 「これでOK」「修正したい」

## 3. 画面ごとの説明

### 3-1. 名前選択（藤田鉄工所版のみ・初回だけ）

黒い画面に「どなたとして確認しますか？」と出て、
**米倉社長 / 吉田さん / 三浦さん** の3つのボタンが縦に並ぶ。

- 選んだ名前は端末に保存され、**2回目以降は出ない**
- 右上に常に「**米倉社長 切り替える**」と出ていて、押せばいつでも選び直せる
- 間違えて他人の名前で押してしまった場合の逃げ道がこれ

KING PLANTS版はこの画面が出ない（小野寺さん固定）。

### 3-2. タブ（藤田鉄工所版のみ）

上部に **プロジェクト｜プロダクト｜YouTube**。
横の**赤い数字は「その人がまだ見ていない投稿の件数」**。
自分が確認を押すと数字が減る。3人それぞれで数字は違う。

### 3-3. Instagram リールの見え方

- 全画面の縦動画（9:16）
- 右に上から：いいね／コメント／シェア／保存／「…」／音源のジャケット
- 左下に：アカウントのアイコン＋ユーザー名＋「フォロー」ボタン、音源名、キャプション1行
- 共同投稿のときは、実際のInstagramと同じく**アイコンが2つ重なり、
  `fujita_stainless と kingplants_pot` と2アカウント名が並ぶ**

### 3-4. Instagram フィードの見え方

いつものフィード投稿の形。上にアカウント行、真ん中に4:5の画像、
下にアイコン列とキャプション。

- **写真が複数枚のときは横スワイプ**。下に白い点（●○）、右上に「1/2」

### 3-5. YouTube（ショート／動画）の見え方

Instagramと同じ見た目だと違和感が出るので、YouTube用の別レイアウト。

- 右のアイコンは：高評価／コメント／**共有**／**リミックス**／チャンネルアイコン
- 左下に「@藤田鉄工所」＋**チャンネル登録**ボタン、その下に2行のタイトル
- 下のタブバーは **ホーム／ショート／＋／登録チャンネル／マイページ**
- 再生バーは赤

### 3-6. 動画の再生

- **自動では再生されません。**画面の真ん中の▶︎をタップすると再生が始まる
- 再生はGoogleドライブのプレイヤーで行われる（音量や全画面はそのプレイヤーの操作）
- 読み込みに数秒かかることがある

## 4. キャプション（文章）の読み方 ★資料の山場

投稿画面と同じで、**最初は1行だけ**しか見えていない。末尾に「…続きを読む」。

**そこをタップすると、下から白／黒のパネルがせり上がってきて全文が読めます。**
実際のInstagramでキャプションを開いたときと同じ動き。

### Instagram のパネル（黒）

上から順に：

1. 「投稿内容」の見出しと ×（閉じる）
2. アカウント名
3. 音源名
4. **キャプション本文（改行そのまま）**
5. ハッシュタグ（青文字）
6. 投稿予定 8月12日 19:00　・　リール
7. 場所（入れていれば）
8. **これまでの確認**（→ §5）
9. 一番下に **[これでOK] [修正したい]**

### YouTube のパネル（白）

YouTubeの「概要」画面をなぞっている。

1. 「概要」の見出しと ×
2. **動画タイトル**（ハッシュタグは青）
3. 四角いタイル3つ：**投稿タイプ／公開予定／ステータス**
4. 概要欄の本文（長いときは「…もっと見る」で全部開く）
5. **これまでの確認**
6. 一番下に **[これでOK] [修正したい]**

閉じるときは × か、パネルの外側の暗いところをタップ。

## 5.「これまでの確認」＝他の人のコメント

同じ投稿を3人が見るので、**過去に誰が何と言ったかが必ず見える**ようになっている。
パネルの下のほうに、コメント欄のような形で並ぶ。

```
吉  吉田さん　8/5 14:20　要修正
    溶接シーンをもう少し長く
```

- 名前・日時・結果（OK＝緑／要修正＝黄）・コメント
- **同じ指摘が重複しないよう、押す前にここを見てもらいたい**というのが狙い
- 記録は上書きされず、ずっと残る

## 6. 確認の押し方

### 「これでOK」を押したとき

- **その場で送信される。**確認ダイアログは出ない
- 「OKを送信しました」と黒い帯が一瞬出る
- ボタンが消えて、緑の「OK」チップだけになる
- タブの赤い数字が1つ減る

### 「修正したい」を押したとき

1. パネルが上がってきて、**コメント入力欄**が開く
2. 何を直してほしいか書く
3. 「修正依頼を送る」を押す
4. 「やめる」で戻れる

**コメントは必須。**空のまま送ろうとすると
「コメントを入力してください。」と赤字が出て送信できない。

入力欄に薄く出ている例文（プレースホルダー）はクライアントごとに違う：

- 藤田鉄工所版：`気になる点や直してほしいところを書いてください`
- KING PLANTS版：`店名の表記、植物の品種名、映り込みなど、気になる点があれば`

### 押したあと

- ボタンが消え、**ステータスのチップ（確認待ち／OK／要修正）だけ**になる
- 同じ人が押し直すことはできない（＝**押し間違えたらぼんちゃんに連絡してもらう**必要がある。
  資料にこの一文を入れたい）
- 押した内容はすぐぼんちゃんにメールで通知される

### 3人の関係

**3人全員が押さないと先に進まない、という仕組みにはなっていない。**
誰か1人が押すとステータスは変わる。運用として「全員に見てほしい」なら、
資料でそう伝える必要がある（→ §8で相談）。

## 7. デザインのトーン

資料の見た目を寄せるなら、このあたりを参考に。

- **全体は黒**（Instagram/YouTubeのダークモードに合わせている）
- 決定ボタンの青は **#0095f6**（Instagramの青）
- ステータスの色：確認待ち＝グレー／**OK＝緑**／**要修正＝黄**
- ハッシュタグ・リンクは青
- 文字は日本語のシステムフォント（ヒラギノ）
- **スマホ縦持ち専用**の設計。PCで開くと画面中央に細長く表示される
- 公式ロゴは一切使っていない（アイコンは汎用の形に置き換えている）

## 9. 資料に入れたほうがよさそうな要素（たたき台）

順番も含めて、これはあくまで案。

1. **これは何？**（1〜2行）— 投稿前の動画を見て、OKか直してほしいかを教えてもらうページ
2. **開き方** — 送られてきたURLをタップするだけ。アプリのインストール不要
3. **最初の1回だけ：自分の名前を選ぶ**（藤田鉄工所版のみ）
4. **見方** — 上下スワイプで次の投稿／▶︎で再生／画面の飾りは押さなくていい
5. **文章を全部読むには** — 「…続きを読む」をタップ ← ここが一番伝わりにくい
6. **他の人のコメントを見る** — 同じところにまとまっている
7. **OK／修正したいの押し方** — 修正はコメント必須
8. **困ったとき** — 動画が真っ黒／押し間違えた／名前を間違えた の3つ
9. **連絡先**

## 10. よくあるつまずき（Q&A用の材料）

| 症状 | 原因と答え |
|---|---|
| 動画が真っ黒のまま | ドライブの共有設定。**先方側では直せないのでぼんちゃんに連絡** |
| 何も表示されない | まだ確認待ちの投稿がないか、通信が不安定。時間をおいて再読み込み |
| 押し間違えた | アプリ上では取り消せない。**ぼんちゃんに連絡** |
| 他人の名前で押してしまった | 右上の「切り替える」で名前を直したうえで、ぼんちゃんに連絡 |
| 文章が途中までしか読めない | 仕様。「…続きを読む」をタップすると全部出る |
| いいねやフォローが押せない | 仕様。飾りなので押せなくて問題ない |
| パスワードは？ | ない。URLを知っている人だけが見られる形なので、**URLを転送しない**ようお願いする |
| PCで見たい | 見られるが、スマホ縦向き前提のデザイン。実際の見え方を確かめるならスマホ推奨 |

## 11. 補足：裏側の仕組み（資料には載せなくてよい）

先方に説明する必要はないが、質問が出たときのために。

- 投稿データはGoogleスプレッドシートで管理していて、1行足すとプレビューに1件増える
- 「OK」「修正したい」を押すと、別シートに記録が追記され、ぼんちゃんにメールが飛ぶ
- サイト自体は静的なWebページ（GitHub Pages）。サーバーもデータベースもない
- URLはランダムな文字列のフォルダ名にしてあり、それが実質の鍵になっている
